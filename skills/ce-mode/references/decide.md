# Decide

**Entry:** a verdict request, a scope request, or a document-review request.

If the request no longer matches this playbook, return to the match table.

Take the one matching step below.

1. **Verdict.** When the request is a verdict on an approach, a document as a whole, or an adoption question, invoke `ce-pov`. Artifact: a graded point of view.
2. **Scope.** When the request is to scope what something should become, invoke `ce-brainstorm`. Artifact: a requirements-only plan, or a chat paragraph.
3. **Document.** When the request is a review of a requirements or plan document, invoke `ce-doc-review`. Artifact: structured findings.

Then follow the shared tail in this skill's kernel.
